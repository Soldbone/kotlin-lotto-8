# kotlin-lotto-precourse
간단한 로또 발매기 구현. 입력 금액에 따라 로또를 추첨해준 뒤 이번 주의 로또 번호를 입력해주면 수익률을 계산해준다.

# 기능
수익률을 출력하고 종료한다.
## 입력 기능
- 구입 금액을 입력 받는다. (1,000원으로 나눠 떨어지지 않는 경우 예외 처리)
- 로또 당첨 번호를 입력 받는다. (1~45 사이의 숫자, 쉼표(,)로 구분)
- 보너스 번호를 입력 받는다. (당첨 번호와 중복되지 않아야 한다.)
- 잘못된 값을 입력할 경우 그 부분부터 다시 입력 받는다.

## 로또 발매 기능
- 구입 금액에 해당하는 만큼 로또를 발행한다. (각 로또는 중복되지 않는 6개의 숫자로 이뤄짐)

## 출력 기능
- 발행한 로또 수량 출력. 로또 번호는 오름차순 정렬된 상태로 출력한다.
  > 8개를 구매했습니다.\
  [8, 21, 23, 41, 42, 43]\
  [3, 5, 11, 16, 32, 38]\
  [7, 11, 16, 35, 36, 44]\  
  [1, 8, 11, 31, 41, 42]\
  [13, 14, 16, 38, 42, 45]\
  [7, 11, 30, 40, 42, 43]\
  [2, 13, 22, 32, 38, 45]\
  [1, 3, 5, 14, 22, 45]
- 당첨 내역 출력
  > 3개 일치 (5,000원) - 1개\
  4개 일치 (50,000원) - 0개\
  5개 일치 (1,500,000원) - 0개\
  5개 일치, 보너스 볼 일치 (30,000,000원) - 0개\
  6개 일치 (2,000,000,000원) - 0개
- 수익률은 소수점 둘째 자리에서 반올림하여 출력 (ex. 100.0%, 51.5%, 1,000,000.0%)
  ```
  1등: 6개 / 2,000,000,000
  2등: 5개 + 보너스 / 30,000,000
  3등: 5개 / 1,500,000
  4등: 4개 / 50,000
  5등: 3개 / 5,000
  ```
- 사용자가 잘못된 값을 입력할 경우 "[ERROR]"로 시작하는 에러 메시지를 출력

## 예외 처리 기능
- 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨다.
  - 구입 금액은 1,000의 배수여야 한다.
  - 로또 당첨 번호 입력은 1~45 사이의 숫자이고, 쉼표(,)로 구분되어야 한다.
  - 보너스 번호는 나머지 6개의 번호와 같을 수 없다.
