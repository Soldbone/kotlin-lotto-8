# 로또 (kotlin-lotto-precourse)
## 프로젝트 소개
이 프로젝트는 간단한 로또를 구현합니다.
- 로또 1개의 가격은 1,000원입니다.
- 로또를 구입할 금액을 입력하면 해당 금액에 맞는 개수의 로또를 발급하여 보여줍니다.
- 로또 추첨 결과로 나온 당첨 번호를 입력합니다.
- 모든 입력이 완료되면 당첨 통계를 출력하고 종료합니다. 다음과 같은 정보가 포함됩니다.
  - 각 등수별 당첨된 로또의 개수
  - 수익률 (소수점 둘째 자리에서 반올림)
- 각 등수별 등수 산정 조건과 상금은 다음과 같습니다.
  - 1등: 6개 번호 일치 / 2,000,000,000원 (20억 원)
  - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원 (3천만 원)
  - 3등: 5개 번호 일치 / 1,500,000원 (150만 원)
  - 4등: 4개 번호 일치 / 50,000원 (5만 원)
  - 5등: 3개 번호 일치 / 5,000원 (5천 원)

## 기능 목록
### 입력 기능
- 로또 구입 금액을 입력받는다.
- 당첨 번호와 보너스 번호를 **각각** 입력받는다.
- 입력에 오류가 있어서 끊긴 경우 입력이 끊긴 부분부터 입력을 받는다.

### 출력 기능
- 발급된 로또 번호를 각각 오름차순으로 출력한다.
- 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력한다.
    - `Exception`이 아닌 `IllegalArgumentException`, `IllegalStateException` 등과 같은 명확한 유형을 처리한다.
    - 에러 메시지를 형식에 맞춰 출력한다.
    - 다음과 같은 경우 에러 메시지를 출력한다.
      > - 금액이 **양의 정수**가 아닌 경우<br>
      > - 당첨 번호 숫자의 범위가 1~45가 아닌 경우
      > - 중복되는 숫자가 있는 경우
      > - 뽑은 숫자, 보너스 번호가 각각 6개, 1개가 아닌 경우
      > - 입력이 숫자가 아닌 경우
      > - 로또 구입 금액 입력이 1,000원으로 나눠 떨어지지 않는 경우
      > - 당첨 번호 입력이 쉼표로 구분되지 않거나 범위를 벗어나는 경우
- 당첨 통계를 출력한다. 당첨 통계에는 다음이 포함된다.
  - 각 등수별 당첨된 로또의 개수
  - 총 수익률

### 로또 발행 기능
- 입력받은 로또 구입 금액에서 발행할 수 있는 만큼 로또를 발행한다.
- 발행된 번호를 오름차순으로 정렬한다.
- **1개의 로또**를 발행할 때 **1~45까지의 숫자 중 중복되지 않는 6개의 숫자**를 뽑는다.
    - 제공된 라이브러리인 `camp.nextstep.edu.missionutils.Randoms`의 `pickUniqueNumbersInRange()`를 사용하므로 중복은 없다고 가정한다.
- 입력 받은 당첨 번호를 통해 당첨에 해당하는 로또 정보를 별도로 만든다.
  - 당첨 번호도 오름차순으로 정렬한다.

### 당첨 확인 기능
- 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
    > - 1등: 6개 번호 일치 / 2,000,000,000원
    > - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    > - 3등: 5개 번호 일치 / 1,500,000원
    > - 4등: 4개 번호 일치 / 50,000원
    > - 5등: 3개 번호 일치 / 5,000원
- 일반 번호 및 보너스 번호를 포함하여 일치하는 번호가 몇 개인지 계산한다.
- 일치하는 번호 개수에 따라 등수를 반환한다.

### 당첨 통계 기능
- 발급된 로또 번호와 당첨 번호를 비교하여 각 등수별 당첨된 로또 개수를 계산한다.
- 수익률을 계산한다.
  - 얻은 총 상금을 계산한다.
  - 소수점 둘째 자리에서 반올림한다.
